# 연속 자동 생성 — 작업 기록

> 생성 버튼을 **꾹 누르면** 창이 뜨고, 거기서 **연속 자동 생성**을 켠다.
> 켜져 있는 동안 앱이 **대기열을 계속 채워** 사람이 안 눌러도 그림이 계속 나온다.
> 🎲(추천 축 굴리기)와 짝이 되어 **매번 다른 의상·배경**으로 뽑는 게 목적이다.

- 기획: 2026-09-04 (사용자)
- 대상 레이아웃: **클래식 · 스튜디오** (Anima·이미지변환·인페인팅 제외)
- 상태: **기획 확정 · 시안 단계** (아직 코드 없음)

## 확정된 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 진입 | 생성 버튼 **꾹 누르기**(480ms) + PC 우클릭 | Anima 스윕 메뉴와 같은 조작 |
| 대기열 규칙 | 큐 길이를 **N+1로 유지**(생성 중 1 + 대기 N) | GPU가 한 장 끝나고 쉬지 않게 |
| 대기열 유지 개수 | **사용자가 고른다** (1·2·3) | 원격(Tailscale)은 응답이 늦어 1이면 GPU가 잠깐 쉰다 |
| 중단 | **A안 — 새로 안 넣기만** | 큐에 남은 것은 마저 나온다. 즉시 취소는 안 한다 |
| 상태 저장 | **저장하지 않는다** | 저장하면 앱 열 때마다 몰래 생성이 시작된다 |
| 디자인 | 기본 HTML 컨트롤 금지 · 기존 디자인 토큰 사용 | 사용자 요구 |

## 미리 찾아낸 충돌 지점 12개 (코드 실측)

만들기 **전에** 코드를 훑어 정리한 것이다. 여기 적힌 것은 전부 실제 코드에서 확인했다.

### C1. `_comfySendingFor` 잠금에 자동 보충이 걸린다 — 영영 멈출 수 있다
`comfyGenerate` 는 `lockKey`(`'modal'|'pos'|'neg'`)로 중복 전송을 막고(`index.html:23292`)
`finally` 에서 푼다(`:23383`). 자동 보충이 이 잠금에 걸리면 **그 회차를 조용히 건너뛴다.**
그냥 `return` 하면 다음 기회가 없어 **큐가 비어도 안 채워진 채 멈춘다.**
→ 잠겨 있으면 **짧게 재시도**해야 한다(그냥 포기 금지).

### C2. 🎲 굴리기는 저절로 따라온다 — 그게 이 기능의 핵심이다
`comfyGenerate` 맨 앞에서 `_recRollPickedAxes()` 를 부른다(v9.188.0). 자동 보충이
`comfyGenerate`/`comfyQuickSend` 를 **그대로** 부르면 장마다 굴려진다. 별도 작업 없음.
⚠ **🎲를 안 켜면 같은 프롬프트로 시드만 다른 그림이 무한히 나온다.** 그것도 쓸모는 있지만
사용자가 "랜덤으로 계속"을 원했다면 배신이다 → **창에 🎲 상태를 반드시 표시한다.**

### C3. Anima 와 **ComfyUI 서버 큐를 공유**한다
Anima 는 자기 대기열(`_animaPump`·`_animaPollJob`)을 쓰지만 서버 큐는 하나다.
`_comfySyncQueue` 가 "서버에 있는데 로컬에 없는 job"을 `_comfyJobs` 로 흡수하므로
(`index.html:22047` 주석: *다른 브라우저/ComfyUI 웹 포함*) **Anima 가 뽑는 동안 `_comfyQueueCount` 가 올라간다.**
→ "큐가 N+1 미만이면 보충" 규칙 덕에 **알아서 쉰다.** 안전한 쪽이라 그대로 둔다.
⚠ 다만 Anima 로 옮기면 **끌 버튼이 화면에서 사라진다** → 레이아웃을 벗어나면 자동으로 끈다.

### C4. 「빠르게 생성」(`_multi` job) 과 뜻이 겹친다
`multiGenStart` 는 N장을 한 번에 넣는다. 결과가 섞이진 않지만(`_mgAddResult` 는 `job._multi` 일 때만 탄다)
**두 기능이 동시에 도는 건 사용자에게 혼란**이다 → 자동 생성 중에는 **비활성화**.

### C5. 폰에서 화면을 끄면 멈춘다 — 웹 표준 제약이라 못 없앤다
보충은 ① `_comfyFinalize`(웹소켓) ② `setInterval(_comfySyncQueue, 3000)`(`:22093`) 으로 걸린다.
**백그라운드 탭은 setInterval 이 분당 1회로 throttle** 되고, 폰이 절전에 들어가면 웹소켓도 끊긴다.
→ **"화면을 켜 둬야 계속 돕니다"를 창에 적는다.** 안 적으면 "밤새 켜 뒀는데 3장만 나왔다"가 된다.

### C6. 공유 진입은 **새 문서**다 (v9.176.0)
안드로이드 공유는 `sw.js` 가 `Response.redirect('./index.html?shared=1', 303)` 하므로 앱이 통째로 다시 뜬다.
자동 생성 상태를 저장하면 **공유할 때마다 되살아난다.**
→ **저장 금지.** `_IO_ETC_KEYS` 에도 넣지 않는다(공유 복원 키 `anima_lb_resume_v1` 를 뺀 것과 같은 이유).

### C7. 연결이 끊긴 채 보충하면 토스트 폭탄
`comfyGenerate` 는 핑 실패 시 토스트를 띄운다. 무한 보충이면 그게 계속 뜬다.
→ **연속 실패 3회면 자동 중단** + 이유 표시. 실패 간격은 2s→4s→8s 로 늘린다.

### C8. 꾹 누르기가 일반 클릭과 겹친다 — 클래식엔 그 장치가 아예 없다
Anima 는 `_animaLpEat()` 로 먹지만 그건 Anima 전용 셀렉터(`_ANIMA_PRESS_SEL`)에 묶여 있고
클래식 엔진은 **지연 실행 블록이라 스코프가 다르다** → 그대로 못 쓴다.
⚠ 모바일에서 꾹 누르면 **텍스트 선택·컨텍스트 메뉴**가 뜬다 → `user-select:none` + `contextmenu` preventDefault.
⚠ 꾹 누르고 뗐을 때 **일반 클릭이 같이 터지면** "창도 뜨고 생성도 됐다"가 된다.

### C9. 버튼 교체를 '나열'하면 조용히 샌다
지금 생성 버튼은 **7곳**이다:

| 위치 | 함수 | 비고 |
|---|---|---|
| `#comfy-send-btn` 「생성 전송」 | `comfyGenerate()` | 정적 |
| `#btn-comfy-send-pos` 「ComfyUI 전송」 | `comfyQuickSend('pos')` | 정적 |
| `#btn-comfy-send-neg` 「ComfyUI 전송」 | `comfyQuickSend('neg')` | 정적 |
| 「빠르게 생성」 | `multiGenStart()` | 정적 · **비활성화 대상** |
| 이미지변환 간편 「실행 (생성)」 | `comfyQuickSend('pos')` | **동적 생성**(`simpleRunBtn`) |
| 뉴비 모드 「ComfyUI 생성」 | `comfyQuickSend('pos')` | **동적 생성** |
| 스튜디오 헬퍼 `gen()` | `multiGenStart()` | |

이 목록을 코드에 나열하면 버튼이 늘 때마다 **빠뜨려도 오류가 안 난다.**
(`_animaOptLabel` 이 6개 group 만 나열해 새 축이 캡션에서 빠졌던 것, `known` Set 누락으로
칩이 '기타' 줄로 샜던 것 — 이 프로젝트에서 반복된 사고다.)
→ **`data-pl-gen` 속성으로 잡는다.** ⚠ 동적 생성 버튼 2개는 만들 때 속성을 달아야 한다.

### C10. `data-layout` 게이트를 🎲와 똑같이 쓴다
`_recRollPickedAxes` 가 `document.body.getAttribute('data-layout')` 으로 classic/studio 만 통과시킨다.
⚠ **`_plCurrent` 로 보면 안 된다** — 지연 실행 블록에서 닿지 않는 스코프라 `ReferenceError` 가 나고,
try 로 감싸면 **아무 말 없이 영영 안 돈다**(v9.188.0 에서 실제로 겪었다).

### C11. 중단해도 버튼은 즉시 원래대로
A안(새로 안 넣기)이라 큐에 남은 것은 마저 나온다. 하지만 **자동 생성 상태와 큐 진행은 별개**다
→ 「중단」을 누른 즉시 버튼은 원래 모습으로 돌아가고, 남은 큐는 평소처럼 진행바에 보인다.

### C12. 대기열 유지 개수가 클수록 중단이 늦다
2로 두면 중단해도 최대 2장이 더 나온다. **창에 그 사실을 적는다.**
