# docs/ — 기능별 작업 기록

기능 하나를 만들 때마다 여기에 파일 하나를 둔다.
**설계 결정 · 미리 찾아낸 충돌 지점 · 실제로 터진 문제 · 무엇을 했는지**를 시간순으로 적는다.

`CLAUDE.md` 와의 차이:
- **CLAUDE.md** = 앞으로 코드를 고칠 때 **반드시 지켜야 할 규칙**(짧고 단정적)
- **docs/** = 그 규칙이 나온 **경위와 작업 일지**(길고 서술적). 나중에 "왜 이렇게 했더라"를 찾는 곳

규칙이 될 만한 게 나오면 여기 적은 뒤 **한 줄로 요약해 CLAUDE.md 에도 올린다.**
